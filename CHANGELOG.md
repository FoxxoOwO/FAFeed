# Changelog

All notable changes to FA Feed are documented here. This file follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and uses the version names from
the Android app.

## [Unreleased]

### Added
- Multiple accounts: saved FA logins in encrypted storage, switching in Settings with a
  fresh feed cache so accounts never mix.
- Theme selection (light / dark / system) and optional Material You dynamic colours on
  Android 12+, both in Settings with immediate effect.
- Deep links: HTTPS `furaffinity.net/view/...` and `/user/...` URLs open the submission
  detail or author gallery directly in the app.
- New-post indicators: posts above the stored read baseline get a NEW badge and a count
  in the top bar; tapping the count marks them all read and scrolls to the top, while
  opening a single post clears only its own badge.
- Cloudflare recovery screen: when sync is blocked, a WebView lets the user complete the
  check manually and hands the merged cookies plus User-Agent back to the scraper.
  The DOM probe is shared with the login screen (`WebAuth.kt`).
- Hidden authors: a mute list in Settings filters out posts from selected accounts.
- Author profiles: tapping an author in the feed or in a submission detail opens their
  full gallery, with a button to load older pages.
- Search over loaded posts by author or title, plus rating filters that combine with
  safe mode. The search field replaces the top bar title; the empty-state button clears
  both filters.
- Automatic update checks against the latest GitHub release. The app checks once a day on
  startup (configurable in Settings), downloads the new APK with visible progress and
  hands it to the system installer. A manual check is available in Settings.
- "Later" skips the current release so it is not offered automatically again.
- Unit tests for release parsing, version comparison and APK asset selection.

### Changed
- Session cookies are stored in `EncryptedSharedPreferences` with automatic migration
  from the old plaintext storage; a plain fallback is kept for devices without Keystore.
- Enabled R8/minification for the `release` build type and signed it with the same
  release key. CI still publishes the debug build type.
- Added Compose UI smoke tests, and replaced deprecated `Icons.Rounded` variants with
  their `AutoMirrored` counterparts.
- Signing now uses a real release keystore supplied through `local.properties` locally
  and GitHub Secrets in CI. `app/debug.keystore` is only a fallback for builds without
  signing secrets.
- Enabled `BuildConfig` generation to read the app version at runtime.

> Upgrading from 1.1.2 or older still requires a one-time uninstall: those APKs were
> signed with a keystore generated by each CI runner.

## [1.1.2] - 2026-11-25

### Fixed
- Settings sheet content is scrollable, so the bottom rows ("Open on FA", "Sign out") are
  no longer clipped on short screens or with large system fonts.

## [1.1.1] - 2026-11-17

### Fixed
- Sign-in after FurAffinity moved login to `login.furaffinity.net` and put
  `www.furaffinity.net` behind a Cloudflare challenge. Cookies from both hosts are merged
  and one User-Agent is reused for the WebView, image loading and downloads.
- Cloudflare blocks are reported as a distinct error instead of looking like a bad login.

### Changed
- Android Gradle Plugin updated to 9.5.1.

## [1.1.0] - 2026-10-31

### Added
- English translation and an in-app language switch (System / Čeština / English).
- Thumbnail disk cache with prefetching and a "clear cache" action in Settings.
- Animations for feed/detail navigation, card presses and the NSFW reveal.
- Button to jump back to the top of the feed.
